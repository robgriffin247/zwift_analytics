# Zwift Analytics

## Overview

An app to collect and visualise data related to Zwift racing.

## Data Stack

|----|----|
|Ingestion|dlt & httpx|
|Storage|DuckDB (dev) & MotherDuck (prod)|
|Orchestration|Modal|
|Version Control|Git & GitHub|
|CI/CD|GitHub Actions|
